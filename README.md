# Wallet Check

## Live App
https://wallet-check-roast.vercel.app/

## About the Project
Wallet Check helps people think before spending money.

The user enters:
- The item they want to buy
- The price of the item
- Their pay per hour

The app calculates how many working hours are needed to pay for that item. It also gives a funny message to help users think about their spending.

The app also includes daily coding tasks to help users build good coding habits.

## Main Features
- Calculate the working hours needed to buy something.
- Show the cost of an item in working time.
- Give funny spending messages.
- Try example items and meals.
- Track daily coding tasks and points (XP).
- Choose personal settings and roast level.
- Save progress in the browser.

## How to Use
1. Open the app using the live link.
2. Choose what you want to buy.
3. Enter the price.
4. Enter your pay per hour.
5. View the result and think about your spending.
